# DNS 规则

DNS 与代理路由是两个不同层面。

- **路由规则**决定请求最终进入 DIRECT、代理或具体场景策略。
- **DNS**决定域名通过什么解析路径得到地址。

节点本身正常，但 DNS 路径不合适时，仍可能出现域名超时、解析异常、访问路径与规则预期不一致等问题。

## Hrules 的原则

1. 中国大陆域名优先使用适合大陆网络环境的解析路径。
2. 需要代理的国际服务避免因为 DNS 路径破坏实际分流结果。
3. DNS 配置必须与客户端能力匹配，Mihomo 与 Shadowrocket 不直接共用同一份语法。
4. DNS 只是完整链路的一部分，最终仍以实际 Connections / 请求命中和出口验证为准。

## 排查顺序

遇到“节点能测速但网站打不开”时，不要只检查节点。依次确认：

`域名解析 → 规则命中 → 策略组 → 最终节点 → 实际出口`

Mihomo 的 DNS 配置随对应配置/适配器维护；Shadowrocket 使用自己的 DNS 配置语法。
